# Siamese-Neural-Network
A small-scale project to explore Siamese Neural Networks with different loss functions on image datasets. The codebase is modular and organized like a GitHub repo, making it easy to extend and experiment.

## Features
Implementation of Contrastive Loss and Triplet Loss
Modular structure: datasets, models, losses, training, and utilities separated
Training loops for both pair-based and triplet-based setups
Loss curve visualization for direct comparison

## Dataset
Uses MNIST by default, automatically downloaded via torchvision. No manual setup required.
